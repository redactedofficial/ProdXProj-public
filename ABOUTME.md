# About the maintainer

[redactedofficial](https://github.com/redactedofficial) maintains ProdXProj.

ProdXProj brings project builds, portable production packages, release history,
SSH deployment, and optional central monitoring into one Python workflow. The
aim is to make each release easier to inspect, deploy, and recover using explicit
project configuration.

The project is open source under the [MIT license](LICENSE). Bug reports,
documentation improvements, and contributions are welcome through the
[GitHub repository](https://github.com/redactedofficial/ProdXProj-public).

See the [README](README.md) for setup and capabilities, and the
[security documentation](docs/security.md) for trust boundaries and limitations.
